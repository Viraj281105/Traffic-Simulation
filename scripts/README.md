# Scripts

Development automation, CI/CD helpers, and validation utilities.

## Implemented Scripts

- `validate-schemas.sh` — Shell wrapper script to execute JSON Schema validation.
- `validate_schemas.py` — Python validator script checking configuration, snapshot, and metrics example files against schemas.
- `setup_github.py` — Automation script using GitHub REST API to automatically create labels, milestones, and issues in your repository.

## Planned Scripts

- `setup.sh` — One-command project setup (install local virtual environments and node modules)
- `run-all-tests.sh` — Run backend and frontend test suites

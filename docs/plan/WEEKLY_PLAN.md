# Weekly plan: V3.1 - V6.1

Weeks continue from the earlier phases (this plan is W31 - W60). The version goes up by 0.1 every week and rolls over at .9, the same way V2.9 became V3.0. Weeks run Mon - Fri; "Done by" is the Friday.

- **◆** The Monday of that week is a reserved demo Monday: testing and demo prep only, for both columns
- Feature numbers (#n) are the F-numbers in `FEATURE_SPECIFICATIONS.md`
- Release weeks (W38, W46, W54, W60) tag a public release
- All status values start as TO DO

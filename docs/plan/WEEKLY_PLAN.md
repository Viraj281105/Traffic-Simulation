# Weekly Plan: V3.1 — V6.1

Weeks continue sequentially from earlier phases (this plan covers W31 — W60, plus the V6.1 Grand Showcase). The version increments by 0.1 each week and rolls over at .9. Weeks run Monday through Friday; "Done by" is the Friday date.

- **◆** Indicates a reserved **Demo Monday**: dedicated entirely to system smoke-testing and demo preparation.
- **Feature numbers (#n)** correspond to the specifications in [`FEATURE_SPECIFICATIONS.md`](FEATURE_SPECIFICATIONS.md).
- **Release weeks** (W38, W46, W54, W60) tag formal releases with audits and documentation freezes.

# Next-Gen UI/UX Exploration — Archived

> **Status:** Archived on 2026-10-05 during the V1.0 documentation freeze. **Not a plan and not a description of the application.**

This file previously held an early UI/UX brainstorm ("digital twin command centre": 2.5D/3D rendering, OpenStreetMap ingestion, heatmaps, incident injection, weather effects, a natural-language copilot, spatial audio). It conflicted with the product principles adopted for V1.0 — notably *evidence, not a verdict* (it proposed "winner" HUDs) — and overlapped with both the roadmap and the Future Scope.

Its themes now live in exactly one place each:

| Theme from the brainstorm | Where it is planned now |
| --- | --- |
| Distinct vehicle silhouettes / fleet diversity | [V1.1 — Different Vehicle Types](../ROADMAP.md#v11--different-vehicle-types) |
| Real-world junction layouts | [V1.5 — Real-World Junction Modelling](../ROADMAP.md#v15--real-world-junction-modelling) |
| Scenario comparison and reporting | [V1.7 — Scenario / What-If Planning](../ROADMAP.md#v17--scenario--what-if-planning) |
| Emergency vehicles | [FS-1](future_scope.md#fs-1--emergency-vehicle-priority) |
| Weather and road friction | [FS-7](future_scope.md#fs-7--weather--road-condition-effects) |
| Incident injection | [FS-8](future_scope.md#fs-8--incident--disruption-simulation) |
| Live digital twin | [FS-10](future_scope.md#fs-10--digital-twin-integration) |

Ideas not listed above (3D dashcam view, spatial audio, natural-language copilot, "battle" HUDs) are **not planned**. The original text is preserved in git history at commit `c57d3fa`.

# Shared Contracts

The single source of truth for all data contracts between Backend and Frontend.

**Owner:** Both Developers (joint ownership — changes require mutual approval)

This directory contains JSON Schemas, type definitions, enum definitions, constants, and example payloads. It contains **no executable code**.

See [docs/architecture/04-shared-contract-layer.md](../docs/architecture/04-shared-contract-layer.md) for ownership rules, versioning strategy, and change management process.
